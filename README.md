# Store Management App

A simple inventory and sales manager for a shop, made to run
locally on one computer with low resource usage.

## Technologies

- Python
- Flask (web framework)
- SQLite (database, stored in a single file: store.db)
- pytest (for tests)

## Features

- Product catalog: add, edit, search, and deactivate products
- Stock control: add stock and record exits
- Sales: ring up products, choose payment method (cash / card / QR)
- Cash register: open and close the day, see daily summary
- Low stock alerts
- History of sales and cash closings
- Local web interface (no internet needed)
